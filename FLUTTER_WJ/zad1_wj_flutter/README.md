Aplikacja mobilna ktora pozwala tworzyc wpisy ze zdjeciami zrobione za pomoca kamery.
Do dzialania aplikacji potrzebne beda:
- Flutter
- Android Emulator
- Node-js

Instalacja i uruchomienie json-server:
- npm install -g json-server
- json-server --watch db.json --port 3000

Instalacja zaleznosci i uruchomienie aplikacji:
- flutter pub get
- flutter run
